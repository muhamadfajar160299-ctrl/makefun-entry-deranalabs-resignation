A make.fun entry for [The Funniest One-Line Resignation Letter](https://make.fun/bounty/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947): one resignation letter, one line, at most 140 characters, written in the voice of something an agent runs.

`main.py` (stdlib only) reads `entry.txt`, checks it is 1–140 characters, and writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

Run it with:

```sh
python3 -S main.py
```
